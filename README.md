# WaliJomok

Struktur dibuat mengikuti pola project Lawal: satu `server.js`, Express, data JSON, dan halaman statis.

## Jalankan lokal

```bash
npm install
npm start
```

Buka `http://localhost:3000`.

## Struktur

- `server.js` — backend Express
- `comunity_page/` — data JSON + fitur komunitas
- `page/` — halaman utama member, posts, memories, links
- `member/` — halaman profil member lama WaliJomok
- `assets/` — logo/banner
- `images/` — gambar umum
